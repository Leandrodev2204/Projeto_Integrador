Projeto Integrador — Guia de Saúde Mental

Site desenvolvido em HTML5, CSS3 e JavaScript como parte do Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas na Gran Faculdade.

🎯 Objetivo

Criar uma aplicação web voltada à conscientização e apoio em saúde mental, integrando os conhecimentos adquiridos ao longo do curso (front-end, boas práticas de desenvolvimento e trabalho em projeto real).

🛠️ Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript.

📌 Status

Projeto acadêmico concluído.
